This is a static markdown blog built for writers and developers who want a simple, fast publishing workflow.

## What makes it different

Write markdown, build to static files, deploy to GitHub Pages. No database, no server, no complexity.

The architecture is intentionally simple: markdown files become static JSON at build time. The React frontend fetches that JSON and renders your content.

## The stack

| Layer    | Technology         |
| -------- | ------------------ |
| Frontend | React + TypeScript |
| Build    | Vite               |
| Styling  | CSS variables      |
| Hosting  | GitHub Pages       |
| Content  | Markdown           |

## Who this is for

Writers who want version control for their content. Developers who want to extend the platform. Anyone who wants a simple blog without the overhead of a traditional CMS.

Fork it, customize it, ship it.
